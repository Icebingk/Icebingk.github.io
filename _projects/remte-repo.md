## 项目定位

这是开始学习 **Git 与 GitHub** 时创建的第一个练习仓库。它的内容很少，主要价值不是代码复杂度，而是完成了从本地文件到远程版本库的第一次实践。

## 学习内容

- 理解工作区、暂存区和提交记录之间的区别。
- 练习添加文件、创建提交并查看历史记录。
- 配置远程仓库，将本地提交推送到 GitHub。
- 认识仓库 README 的作用，用简短文字说明仓库用途。

## 当前状态

公开 README 只有“用于学习 Git”的基础说明，没有完整教程或大型代码，因此本页不把它包装成正式软件项目。仓库目前归档保留，作为后续 FPGA、竞赛和个人主页项目使用版本控制的起点记录。
