## 项目背景

该项目用于 **全国大学生集成电路创新创业大赛**，目标是把 RISC-V 处理器与自定义数字接口结合，构建面向物理光学实验的信号采集、处理和显示系统。项目重点不只是实现处理器，而是让处理器能够控制外设并完成实际应用任务。

## 系统架构

系统由简化 RISC-V 处理器核、ADC 采集模块、DAC 输出模块、数据缓存与 HDMI 显示链路组成。处理器负责流程控制和参数管理，自定义 RTL 模块承担连续、高速的数据搬运与时序生成。

完整数据路径为：**模拟信号 → ADC 采集 → FPGA 数据处理/缓存 → RISC-V 控制 → DAC 重构或 HDMI 波形显示**。

## 关键实现

### 三级流水处理器

在已有简化 RISC-V 核基础上进行二次开发，围绕取指、译码/执行和访存/回写的三级流水结构梳理数据通路与控制逻辑。重点处理指令执行、寄存器访问以及处理器与外设寄存器之间的交互。

### ADC/DAC 自定义模块

根据转换器接口时序设计采样和输出控制，使模拟信号能够进入数字系统并在处理后重构。接口逻辑与处理器控制分离，避免处理器逐拍参与高速数据传输。

### HDMI 波形显示

将采样数据转换为可显示的波形坐标，并按照 HDMI 视频时序输出。显示模块把抽象的采样结果变成可直接观察的图像，便于实验人员判断信号变化。

## 联调思路

联调按处理器、转换接口和显示链路分阶段进行。先验证固定测试数据能否正确显示，再接入 ADC 采样；先确认 DAC 或 HDMI 单链路，再验证处理器配置对数据路径的控制。分段替换测试数据可以快速判断问题属于控制路径还是高速数据路径。

## 项目收获

项目让我理解了处理器核与专用 IP 的分工：处理器适合复杂控制，自定义硬件适合稳定、并行和时间敏感的任务。系统级设计需要同时处理地址映射、接口时序、数据带宽和可观察性，而不能只关注单个模块的功能。
