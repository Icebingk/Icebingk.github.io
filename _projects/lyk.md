## 项目背景

该仓库记录 **2024 年电子设计竞赛信号类赛题**的准备与实现过程。信号类题目通常同时涉及模拟前端、嵌入式控制和算法验证，因此项目采用“先分析信号链，再分模块实现，最后整机联调”的方式推进。

## 项目内容

- 根据赛题要求拆分信号输入、处理、控制与输出链路。
- 整理关键芯片的数据手册和接口资料，为供电、引脚连接及参数配置提供依据。
- 保存硬件设计与 PCB 相关文件，便于检查器件连接和后续修改。
- 使用 Python 对关键处理思路进行前置验证，先观察算法结果，再移植到受资源限制的硬件环境。
- 编写嵌入式代码并配合硬件联调，逐步确认单模块与整机行为。

## 实现思路

项目把问题分为三个层次。第一层是模拟与硬件条件，确认输入幅值、频率范围和器件工作状态；第二层是算法与数字处理，用 Python 快速验证计算过程；第三层是嵌入式落地，把算法、控制流程和外设通信放入实际硬件环境。这样可以避免在整机异常时同时怀疑所有环节。

## 仓库组织

公开仓库保留了 Python、C、汇编及项目资料。README 说明原始 Keil 工程体积较大，未全部上传，因此公开内容更适合作为竞赛过程归档，而不是可以直接一键复现的完整发布包。

## 项目收获

这次实践强化了数据手册阅读、信号链分解和软硬件联合调试能力。相比只验证某段程序，竞赛更要求把算法结果、硬件电气条件和时间限制统一考虑，并通过文档归档保证团队能够快速共享当前状态。

## 技术栈
