## 项目目标

这个网站用于集中展示个人介绍、技术能力、工程项目和学习文章。与只放联系方式的简历页不同，网站希望让访问者可以继续点进项目详情，了解项目背景、实际工作、技术路线和验证结果。

## 内容结构

- **首页：** 展示技术方向、代表项目、当前学习重点和进入题库的快捷入口。
- **关于：** 说明 FPGA、数字 IC、嵌入式和工具链能力，并按经历组织个人信息。
- **项目：** 使用 Jekyll Collection 管理项目，项目内容保存在独立 Markdown 文件中。
- **博客：** 通过文章记录工程复盘和学习笔记。
- **题库入口：** 连接到独立部署的牛客专项知识题库，形成“作品展示 + 实际工具”的组合。

## 页面实现

网站使用 Jekyll 和 Liquid 生成静态页面。YAML Front Matter 保存标题、状态、仓库、演示地址和摘要，模板负责统一渲染。CSS 变量构成亮色与暗色主题，JavaScript 记住用户选择并支持系统主题。

项目针对桌面和手机分别设计导航与卡片布局。移动端使用汉堡菜单和更紧凑的内容间距；桌面端保留更完整的网格与视觉层级。页面不依赖大型前端框架，便于直接由 GitHub Pages 构建。

## 动态交互

- 首页背景包含可见的动态光晕、网格和粒子效果，用于增强科技感。
- 项目卡片支持指针跟随高光、悬停抬升和轻微倾斜反馈。
- 页面滚动时内容分批进入，数字统计具有递增动画。
- 移动端提供触摸反馈，并为低性能设备控制动画开销。
- 遵循 prefers-reduced-motion：用户要求减少动态效果时自动关闭非必要动画。

## 发布与缓存

仓库推送后由 GitHub Pages 自动构建发布。静态资源链接加入基于构建时间的版本参数，避免浏览器长期使用旧 CSS 或 JavaScript，解决“代码已更新但页面看不到效果”的缓存问题。

## 当前成果

网站已完成响应式布局、双主题、项目集合、博客入口、交互动效和线上部署。当前阶段继续补充每个项目的工程细节，让主页不仅“好看”，也能真实说明做过什么、如何实现和怎样验证。
