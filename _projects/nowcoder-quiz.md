## 项目背景

牛客专项知识题以网页形式分散展示，原始内容不便离线复习，也难以按照“未做、错题、收藏”等状态反复训练。这个项目将 **764 道数字电路、Verilog 和 FPGA/CPLD 专项知识题**整理为一个手机与电脑均可使用的静态网站，并把题目、参考答案和学习资料放入同一套界面。

## 核心体验

- **逐题模式：** 每次只显示一道题，支持上一题、下一题、键盘方向键和题号导航。
- **即时反馈：** 选择并提交后显示参考答案和解析；非选择题可以单独筛选和阅读。
- **学习筛选：** 支持全部、已做、未做、错题、收藏和非选择题等视图。
- **继续作答：** 刷新页面后保留当前题号和筛选条件，“重做”只重置当前题，不跳回第一题。
- **代码展示：** 识别题干和解析中的代码内容，以代码块展示，提升 Verilog 等题目的可读性。
- **资料复习：** 将数字逻辑、Verilog、SystemVerilog、VHDL 与 FPGA 阅读资料整合到题库页面。

## 数据与同步设计

网站采用 **本地优先**策略。未登录或断网时，答题记录、错题和收藏先保存在浏览器 localStorage 中；登录后再与 Supabase 云端同步。这样网络短暂中断不会阻止刷题。

云端使用 Supabase Auth 进行邮箱登录，PostgreSQL JSONB 保存用户进度，Row Level Security 确保用户只能访问自己的记录。针对“手机登录后覆盖电脑进度”的问题，同步逻辑改为安全合并：比较本地、云端和最近同步快照，合并双方新增记录，并在写回前保留恢复备份。

## 进度迁移

项目提供 JSON 导出和导入。用户可以先在原设备导出本地进度，再在登录状态下导入并同步到云端；此后手机和电脑使用同一邮箱即可继续。导入前保留旧数据副本，降低误覆盖风险。

## 部署方式

前端使用静态 HTML、CSS 和原生 JavaScript，不依赖应用服务器。代码推送到 GitHub 后由 GitHub Pages 发布并提供 HTTPS；Supabase 只承担身份认证与用户进度存储。题库本身仍可静态加载，因此部署成本和维护复杂度较低。

## 项目结果

项目已经从单一长页面演进为可答题、可复习、可筛选、可收藏并支持云同步的学习工具。公开页面可直接使用，仓库同时保留部署说明和数据迁移方法。
